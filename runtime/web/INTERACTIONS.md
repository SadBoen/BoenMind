  建议改为文本路径输入,不走系统目录选择)

- provider 行数据结构对齐(解开 #10 的 disabled)

## 测试环境注意(踩坑记录)

- 模块缓存:改 plugins/*.js 后必须更新 index.html 内 __DSH_BOOT__ 的 rev
  值破坏缓存(无缓存头,浏览器咬旧文件)
- 每项交互必须独立 fresh 页面;复用状态会互相污染(收起侧栏后其余按钮
  全部隐藏,造成假失败)
- playwright 语义定位偶发 actionability 超时:IAB 已知问题,兜底用页面
  事件 evaluate(btn.click())
