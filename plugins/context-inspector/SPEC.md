# 插件规格：上下文透视与分析器 (context-inspector)

> 规格定位：官方第二款自带插件（纯前端与诊断分析面），用于实时解剖、透视和分析大模型对话过程中的 Prompt 配方与 Token 消耗。
> **铁律原则**：
> 1. **只读透视，绝不压缩**：本插件绝不修改对话数据，不执行滑动窗口裁剪，不执行摘要压缩（压缩为后续独立 MCP 插件职责）。
> 2. **人类友好第一**：默认展示必须使用非程序员也能秒懂的日常语言（人设规矩、特长技能、电脑目录、工具背包、聊天记忆），禁止技术黑话堆砌。
> 3. **专家模式兼备**：保留一键切换查看底层 Raw JSON 报文的能力，方便技术排查。

## 一、架构职责分工

```text
┌───────────────────────────┐
│     Runtime 内核 (Rust)   │ 
│  - 负责在调用模型前精准快照   │
│  - 产出 context-log.jsonl │
└─────────────┬─────────────┘
              │ HTTP /admin/context (纯数据流)
              ▼
┌───────────────────────────┐
│ context-inspector (插件)   │
│  - 结构解析与语义归类       │
│  - 人类语言转换与占比计算   │
│  - 容量水杯与健康度告警     │
│  - 执行轨迹步骤化呈现       │
└───────────────────────────┘
```

## 二、人类友好翻译法则

| 技术字段 | 界面友好表达 | 作用说明 |
|:---|:---|:---|
| System Prompt - Base | 🎭 AI 的人设与规矩 | 告诉 AI 它是谁、该如何说话 |
| System Prompt - Skills | ⚡ 携带的特长技能 | 当前挂载的专业技能指令包 |
| System Prompt - Workspace | 📁 允许查看的电脑目录 | 限制或提示 AI 的工作文件夹路径 |
| Tools Schema | 🛠️ 装备的工具箱 | AI 拥有的功能列表（会占用背包容量） |
| History Messages | 💬 之前的聊天记忆 | AI 还记得的上文对话（轮数与字数） |
| Evicted Turns | ✂️ 已经忘掉的旧对话 | 因超出容量被移出的历史，提示用户为何失忆 |
| Tokens / Latency | 📏 篇幅容量 / ⏱️ 思考耗时 | 换算为字数和百分比，以及人类习惯的秒数 |

## 三、界面呈现三层漏斗

1. **第一层：健康度看板（容量水杯）**
   - 总体容量占比条（人设 / 技能 / 工具 / 记忆 / 提问 颜色区分）
   - 思考耗时、真实输入字数、回复字数
   - 健康状态徽标（🟢 记忆完好无遗漏 / 🟡 存在较早对话脱落）

2. **第二层：配方卡片盒（四块核心内容）**
   - 【人设与技能卡片】：查看当前生效的角色名、特长技能及生效文本。
   - 【工具箱卡片】：列出所有挂载的工具，标明只读直通还是需要人工审批，并计算工具参数说明占用了多少背包空间。
   - 【聊天记忆卡片】：时间轴式展示 AI 脑海中保留的对话轮次；如果存在被自动丢弃的轮次，用剪刀图标明显标识。
   - 【本轮提问卡片】：用户输入的原始提问。

3. **第三层：执行轨迹瀑布（Tool Turns）**
   - 如果发生工具调用，展示：提问 -> AI 决定调用某工具 -> 本地运行完毕返回结果 -> AI 组织最终答复。

4. **辅助功能：专家模式（Raw View）**
   - 支持一键展开/切换真实的请求 JSON（OpenAI 格式），支持一键复制到剪贴板。
