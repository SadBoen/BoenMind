# 插件规格：上下文透视与分析器 (context-inspector)

> 规格定位：官方首款自带只读透视分析插件，用于实时解剖、透视和分析大模型对话过程中的 Prompt 配方与 Token 消耗。
> **铁律原则**：
> 1. **只读透视，绝不压缩**：本插件绝不修改对话数据，不执行滑动窗口裁剪，不执行摘要压缩（压缩为后续独立 MCP 插件职责）。
> 2. **人类友好第一**：默认展示必须使用非程序员也能秒懂的日常语言（人设规矩、特长技能、电脑目录、工具背包、聊天记忆），禁止技术黑话堆砌。
> 3. **专家模式兼备**：保留一键切换查看底层 Raw JSON 报文的能力，方便技术排查。
> 4. **数据严格保真，绝不编造假数字**：未登记、未上报或不可测指标（如未配置窗口大小、未细分上报思考/缓存 token、非流式首字）必须如实标记「未上报/未登记/不可测」，严禁按固定比例或名称字典冒充真实测量。

## 一、架构职责分工

```text
┌────────────────────────────────────────┐
│           Runtime 内核 (Rust)           │ 
│  - 负责在调用模型前精准截取请求快照     │
│  - 捕获流式 TTFT 首字与 Usage 细分     │
│  - 统计台账累计回合与真实遗忘裁剪轮数   │
│  - 产出 context-log.jsonl              │
└──────────────────┬─────────────────────┘
                   │ HTTP /admin/context (纯数据流)
                   ▼
┌────────────────────────────────────────┐
│       context-inspector (内置前端面)    │
│  - 结构解析与语义归类                  │
│  - 人类语言转换与构成占比              │
│  - 模型窗口水位(读 model.json 登记值) │
│  - 真实遗忘轮次与健康度告警            │
│  - 全域左卡片+右代码双栏联动高亮       │
│  - 文件副作用追踪与多轮暴增诊断        │
└────────────────────────────────────────┘
```

## 二、人类友好翻译法则

| 技术字段 | 界面友好表达 | 作用说明 |
|:---|:---|:---|
| System Prompt - Base | 🎭 AI 的人设与规矩 | 告诉 AI 它是谁、该如何说话 |
| System Prompt - Skills | ⚡ 携带的特长技能 | 当前挂载的专业技能指令包 |
| System Prompt - Workspace | 📁 允许查看的电脑目录 | 限制或提示 AI 的工作文件夹路径 |
| Tools Schema | 🛠️ 装备的工具箱 | AI 拥有的功能列表（会占用背包容量） |
| History Messages | 💬 之前的聊天记忆 | AI 还记得的上文对话（存活轮数与字数） |
| Evicted Turns | ✂️ 已经忘掉的旧对话 | 会话累计回合与台账存活差值，真实提示用户是否失忆 |
| Tokens / Latency | 📏 篇幅容量 / ⏱️ 思考耗时 | 换算为字数和百分比，以及人类习惯的秒数 |
| TTFT (Time to First Token) | ⚡ 首字延迟 | 流式首个增量块到达时间，如实反映网络与排队延迟 |

## 三、界面呈现三层漏斗

1. **第一层：健康度看板（容量水杯）**
   - 总体容量占比条（人设 / 技能 / 工具 / 记忆 / 提问 颜色区分）
   - 思考耗时、首字延迟（流式）、真实输入/输出 token、缓存命中
   - 模型窗口水位（依用户在设置中心登记值计算；未登记诚实显示未知并引导录入）
   - 记忆健康度（依真实 evicted_turns 计算；>0 明确警告被剪轮数）

2. **第二层：全域双栏联动配方区**
   - 【人设与特长双栏】：左侧卡片，右侧系统提示词原文段落平滑滚动加深高亮。
   - 【工具背包双栏】：左侧大白话卡片（标明只读直通/需审批与背包占用），右侧 OpenAI Function JSON 专家代码联动。
   - 【聊天记忆双栏】：左侧各轮对答摘要，右侧 Messages 原始报文联动；底部真实说明遗忘现状。
   - 【工程文件副作用双栏】：捕获当前会话涉及的 `fs.*` / `system.exec` 文件操作，按文件聚合展示最新行为与操作指令明细。
   - 【Token 暴增诊断】：对比多轮输入增量，标记异常暴增刺客。
   - 【步骤时序流】：串联工具调用、反馈、模型思考链与最终回复。

3. **辅助功能：专家模式（Raw View）与脱敏导出**
   - 支持一键展开整轮原始 OpenAI JSON 请求报文；
   - 支持一键导出脱敏后的诊断 JSON 数据包。
