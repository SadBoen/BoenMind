# W3 实现规格:主题系统(两级换肤)——需求登记版

- 序列:WEBUI W3(前置:W2 设置中心完成后定稿动工;依赖 W2 的设置页骨架
  与「外观」导航位)
- 状态:**已实现并通过浏览器验收(2026-09-01/02,验收记录见 §6)**
- 用户原话要点:「W3 主攻风格切换,风格自定义为两级:一级是主题(古典/
  现代/卡通/玻璃),二级是每个主题有设置项(配色、透明度、背景这些)。
  不是所有主题都有相同的设置,比如透明度就只有玻璃主题有」

## 0. 实现裁决登记(2026-09-01/02)

1. **视觉稿**(§4 裁定「摸爬 showcase 直接利用」+ 视觉稿先行纪律):玻璃=
   已认可样张(.tools/mockups §4.1)直落;古典/卡通=样张草案落地(裁决
   问询超时按推荐项执行:做完可视化验收给用户过目,不满意按令牌微调);
   现代=W1 现状令牌(不采纳样张里 assistant-ui zinc 深色 accent 变体,
   规格明确「现代=W1 现状」)。
2. **实现形态**(§2):`src/w3/themes.ts` = 主题注册表(每主题 schema:
   项名/类型/默认/取值域/应用函数)+ applyTheme(html data-theme + inline
   变量,先清后写防残留)+ localStorage(`bm_theme`,每主题设置独立
   保存);`src/w3/theme.css` = 四主题令牌块+专属效果(单一来源纪律:
   同 selector 的 background 只写一处,玻璃 body 背景规则仅 §4.1 一处);
   `AppearancePage` = 主题卡片四选 + 当前主题 schema 动态表单(实时预览
   = onChange 即 apply)+ 全局文字大小(§4 裁定:不入主题,存
   `bm_font_size`)。assistant-ui 选装组件走 shadcn 桥接变量,天然随
   主题换肤(W2 §0.4 共存策略兑现)。
3. **设置项清单落定**(§3 初稿 + §4 裁定;主配色=全部通用):
   - 现代:主配色、紧凑度(消息垂直密度)
   - 古典:主配色、衬线强弱(无/Georgia/宋体系)、纸色深浅(三档)、行距
   - 卡通:主配色、圆角大小、配色活泼度(三档,联动色影浓度)、
     表情装饰开关(html data-emoji 挂 content)、文字字体(卡通/幼圆/楷体)
   - 玻璃:主配色(半透明派生)、**透明度**(仅玻璃)、模糊强度、
     背景图(默认内置樱花 /themes/sakura.jpg,可本机自定义 dataURL)、
     背景暗化
4. **花瓣层修复**(实现期踩实):App 的主题快照不随切换更新,花瓣要
   刷新才出现 → 改 MutationObserver 监听 html[data-theme],切换即时
   挂/卸(验收:玻璃12→现代0→玻璃12)。

## 1. 需求(用户意图结构化转写)

1. **一级:主题预设**4 个,内置:
   - 古典:衬线字体、纸墨/暖色调、传统版式
   - 现代:即 W1 现状(浅色、细边框、专业开发工具风)
   - 卡通:大圆角、明快配色、活泼氛围
   - 玻璃:半透明毛玻璃(blur)、通透层次
2. **二级:主题内设置项**,每个主题自带清单,项集**不必相同**:
   - 例:配色(主色/强调色)、背景(纯色/图)
   - 例:透明度——**仅玻璃主题有**
3. 换主题 = 全站换肤:三栏、对话、设置、消息全部随令牌切换
4. 主题选择与各主题设置项持久化(重启保持)

## 2. 技术形态(实现时定稿)

- 底座 = W1 已建立的 CSS 设计令牌(styles.css :root 变量表);主题 =
  令牌预设覆盖 + 少量主题专属样式类
- 每主题「设置项清单」= 该主题自带的 schema(项名/类型/默认值/取值域),
  设置页据此动态渲染表单——**每主题 schema 不同**正是用户要求的核心
- 持久化:W3 先 localStorage,随 W 系列配置中心(§W2 恢复 config API)
  收编为服务端配置
- assistant-ui 关系:主题系统为**自有组件**(纯令牌层,不触碰对话原语);
  assistant-ui 原语自身无样式假设,天然随令牌换肤

## 3. 主题设置项清单(初稿,定稿与用户逐项过)

| 主题 | 设置项 |
|---|---|
| 全部通用 | 主配色 |
| 古典 | 衬线字体强弱、纸色深浅、行距 |
| 现代 | 紧凑度、强调色 |
| 卡通 | 圆角大小、配色活泼度、表情装饰开关 |
| 玻璃 | **透明度**、模糊强度、背景图、背景暗化 |

## 4. 用户补充裁定(2026-09-01 深夜口述,已定)

1. **文字大小与主题无关**(属全局/偏好设置,不入主题 schema);
   **文字字体可入主题**:如卡通主题可设可可爱爱的字体
2. **背景支持自定义图片**,但按主题开启:如「现代」主题**只能改配色,
   不开自定义背景**;有背景项的主题才能用自定义图
3. **实时预览**:能做到就做(改设置项即时生效)
4. **视觉稿来源**:找技能/专业网站出稿;优先摸爬
   assistant-ui showcase(www.assistant-ui.com/showcase),盘点可
   直接利用的成品/半成品样式(用户明示:直接利用,效率优先)

## 5. 验收门(沿 W 序列固定流程:浏览器 MCP 可视化验收)

1. 四主题一键切换,全站(三栏/对话/设置/消息)同步换肤,刷新保持
2. 各主题设置项动态渲染正确(玻璃见透明度,其他主题不见)
3. 设置改动即时生效且重启保持
4. 对话闭环回归(banana 实测)不退化
