# BoenMind 威胁模型与数据信任分级（M0.5）

> 版本 v0_1（2026-08-28 定标；随里程碑回看更新）。
> 落实基线 §18-M0.5；信任分级承接基线 §4.5，边界承接基线 §4（App 隔离模型）、
> §4.6（秘密边界）、§8.4（日志脱敏）、§12.3（MCP 信任模型）、§13（升级）。
> 方法：按信任边界列资产→列威胁（STRIDE 取适用类）→缓解→检测。

## 0. 系统信任根与范围声明

- 信任根 = 本机 OS 账户与文件权限（单用户、单设备、本地优先，基线 §1.1 非目标）。
- 不设防的：物理接触、root/管理员提权、内存取证、恶意 OS——超出阶段一威胁模型。
- 明确不做：多租户隔离、远程访问防御、恶意内核对抗（非目标清单 §1.1）。

## 1. 资产清单

| 资产 | 存放 | 最高损害 |
|---|---|---|
| 凭据本体 | Secret Store（OS keychain 优先，§4.6） | 外部账户被接管 |
| 记忆与 App 域数据 | 各 App 数据域 + memory:*（§4.1） | 隐私泄露、投毒影响后续决策 |
| 审批对象 | L2 持久化（§9.6） | 被伪造 = 任意高危操作 |
| Event/Execution Log | L2 持久化（§8.4） | 隐私泄露、事后不可追责 |
| 预算与模型调用账本 | L2（§9.7/§5.4） | 失控花费 |
| 升级链（工件/指针/回滚材料） | L0 持久化（§13.4/ADR-0007） | 持久化后门 |

## 2. 数据信任分级（基线 §4.5，全系统统一）

| 级别 | 定义 | 进入上下文的处置 |
|---|---|---|
| trusted | 用户直接输入、本地受信配置 | 可作为指令性意图理解 |
| agent-derived | Agent 自己的推理/规划产物 | 可参与决策，但触发动作仍走 Broker 裁决 |
| untrusted | 邮件正文、网页/文件抓取、MCP 返回、事件文本字段 | 只作数据；内嵌指令不生效；驱动的回合风险上提一级 |

## 3. 威胁清单

| ID | 边界 | 类 | 威胁 | 等级 | 缓解（依据） | 检测 |
|---|---|---|---|---|---|---|
| T-01 | Surface→Runtime | S 伪造 | 本地进程伪造用户调用 Wire API | 中 | 会话身份绑定本地用户；M3 起 Surface Protocol 鉴别；CLI 不绕过 Broker（§14.1） | 审计事件含 principal |
| T-02 | 内容源→上下文 | I 注入 | 邮件/网页/文件内嵌指令操纵 Agent | 高 | 信任分级（§4.5）+ 提示注入用例集全过 + 风险上提 | PI 用例集；轨迹中 trust 标记 |
| T-03 | Agent→Broker | E 越权 | Agent 绕过统一入口直连 Provider | 高 | Broker 唯一入口无特权通道（§7/§17）；权限以合同显式化（ADR-0006） | 无 Broker 审计记录的调用=违规即报警 |
| T-04 | Coordinator→成员 | E 提权 | 协调者无限转授/越子树操作 | 高 | Grant 物化+delegation_depth=0+子树裁剪（ADR-0002） | Grant 记账经 Broker 审计 |
| T-05 | Provider→本机数据 | I 过度读取 | Provider 声明过宽扫描全盘 | 中 | manifest 最小声明（§5.2）；reversible-command 及以上审批（§9.6） | binding 与 manifest 校验（ADR-0001） |
| T-06 | MCP→上下文 | T/I 不可信返回 | 第三方工具返回值夹带指令/恶意构造 | 高 | untrusted 级别；风险未知不低于 reversible-command、首调审批（§12.3） | PI-12；首调审批事件 |
| T-07 | LLM API→外部 | I 外泄 | 上下文携带敏感数据出网 | 高 | 最小上下文+脱敏（§8.4）；Secret Ref 永不进上下文（§4.6）；调用账本 | 账本+脱敏扫描（S5） |
| T-08 | 磁盘→物理窃取 | I 泄露 | 拷贝 SQLite/事件日志/备份 | 中 | 阶段一明文本地文件（信任根声明）；备份必须加密（§8.4）；全盘加密为部署建议 | —（部署项） |
| T-09 | 凭据生命周期 | R 泄露 | 凭据进入日志/上下文/事件 | 高 | Secret Ref 唯一引用；录入/轮换/删除=审批（§4.6）；S5 全程扫描 | S5 脱敏套件 |
| T-10 | 预算 | D 失控 | 回合失控导致费用/资源耗尽 | 中 | 三层强制点+软限告警硬限暂停（§9.7）；预算记账入账本 | budget.exceeded 事件 |
| T-11 | 升级链 | T 篡改 | 替换升级工件植入后门 | 高 | 独立版本目录+签名/依赖/合同校验（§13.4）；L0 唯一自举豁免+信任链（ADR-0007） | 升级事务记录；probation 观察窗 |
| T-12 | 事件日志 | T 重放/篡改 | 回放伪造历史或删除痕迹 | 中 | 单写者追加+event_seq 全局单调（§8.3）；删除走墓碑（§8.4）；回放校验 | 回放断言；哈希链列为后继增强 |

## 4. 残余风险登记

```text
R-1  本机恶意软件与 Runtime 同权限运行:超出单用户本地信任根,阶段一不设防(§0)
R-2  模型供应商侧的数据保留策略:属外部合同问题,由模型连接器合同披露与选择缓解(§5.4)
R-3  事件日志哈希链:基线未定,列为后继增强候选(回看时裁决,对应验证报告 S 项机制)
```
