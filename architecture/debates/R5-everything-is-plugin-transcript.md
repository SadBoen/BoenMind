# Zen Consensus 辩论记录:R5 万物皆插件:内核只有合同与最小机制

辩论对象:§17 裁决 R5「万物皆插件:内核只有合同与最小机制」

> 协议:Zen consensus——三个不同模型家族担任三方(FOR=架构师钢人论证,AGAINST=安全可靠性挑战,EMPIRICAL=真实系统实证裁决),两轮(独立立场→交叉质证),缺席与不可裁决的分歧如实记录。

角色分配:AGAINST=gpt-5.6-luna, EMPIRICAL=gemini-3.7-flash, FOR=glm-5-turbo

## 裁决原文

裁决:内核只由合同与最小机制组成,其余一切都能在不修改内核的前提下增加、替换和移除;模型连接器、记忆引擎、定时器、评价器、Secret Store 都是扩展点上的普通 Provider,不是内核特权组件;新增功能默认走插件路径(Provider/App/Surface/Skill 以普通身份注册),只有既有扩展点无法表达时才允许改合同,且必须按 §13.5 升级级别处理并先证明该抽象无法用既有扩展点表达;内核每增加一个内建特权功能都必须给出「为什么不做成 Provider/App」的理由。
