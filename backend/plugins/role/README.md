# Role Definition（角色定义）

角色 = 助手的人格/职责设定。创建角色 → 激活角色 → 宿主在每次模型请求前把
当前角色的指令文本注入系统提示，角色切换**立即生效**，无需重建会话。

## 使用

对助手说即可（或直接调 `role` 工具）：

- 「查看当前角色 / 角色列表」 → `role(op:list)`
- 「切换角色到 xxx」 → `role(op:set, id:xxx)`
- 「扮演一名资深 Rust 工程师……」→ 模型侧会自动用 create + set 两步完成
- 「取消角色」 → `role(op:clear)`

## 数据

- 存储：`~/.boenmind/roles.json`（插件独占写入，宿主只读注入）
- 结构：`{ "active": "<id>|null", "roles": [{ "id", "name", "prompt" }] }`
- 边界：id ≤ 48 字符（小写字母/数字/中划线），name ≤ 64，prompt ≤ 2000 字符
  （注入是有界字符的原则，对齐记忆注入）

## 架构

- 插件侧（本目录）：角色增删改查 + 激活切换（`role` 工具，模型可调）；
- 宿主挂点（`bm-server/src/roles.rs`）：`on_request` 读取当前激活角色并追加
  进 system 消息——与记忆注入（bm-memory）同款"插件管策略、宿主给挂点"分工；
- 角色文件缺失/损坏 → 静默不注入（fail-open），不阻断对话。

## 已知边界

- 角色是全局设定（所有会话共享）；按会话/按应用的角色隔离留 manifest scopes
  （架构 §四·C）落地时扩展。
