# 京东（jd.com）— 高难；VPS 已判放弃，桌面端待重测

**难度 4/5，自研风控。2026-08 在海外 VPS（数据中心 IP）实测：无解，任何浏览器引擎都打不穿。**
**但注意反检测基准结论：IP 权重 > 引擎权重——桌面端（大陆住宅/办公 IP）结论可能不同，重测后更新本笔记。**

## 结论（VPS 环境实测）

- 实时价格唯一可行路径 = **登录态 cookie（pt_key/pt_pin，绑定设备指纹，7~30 天过期）+ 中国大陆 IP**（香港 IP 不过地理校验）
- 价格微服务 p.3.cn / c0.3.cn 是基础设施级 WAF，代理流量全挡
- 单 IP 硬限 ~100 请求/小时；搜索页滑块验证码；动态 HMAC-SHA256 签名
- 未登录时：商品页 → 风控页；搜索页 → 200 但纯 JS 空壳（0 个 p-price 节点）

## 实测记录（2026-08，VPS）

| 方式 | 结果 |
|---|---|
| curl（浏览器 UA） | 商品页弹风控页（risk_handler，2.7KB 验证墙）；搜索页 50KB 空壳，0 商品节点 |
| Obscura --stealth | 商品页 41B 验证墙；搜索页 1.4KB"请使用高版本浏览器"（UA 被识别异常） |
| nodriver 真 Chrome 151 | 页面完整加载（导航/登录栏都在），但搜索区显示"抱歉由于访问频繁导致无法搜索"、0 商品节点 → **IP 层限流，与浏览器引擎无关** |

## 可用路径（如确需京东数据）

- 非价格元数据（标题/图片/参数）：curl_cffi + Chrome TLS 伪装 + 大陆住宅代理，轻量可行
- 价格数据：登录态 cookie + 大陆 IP + stealth 浏览器（Camoufox/Patchright），sticky session
- 第三方聚合 API（如 appapi.maishou88.com，openid 方式）是绕过浏览器的务实替代
- 用户明确拒绝付费爬虫 API（Bright Data/ScrapingBee/ZenRows 等直接排除）

## 桌面端重测结论（2026-08-12，大陆网络 + 真浏览器）

**登录墙取代了风控页——结论不变：未登录不可直接采集。**

| 页面 | curl（浏览器 UA） | 真浏览器 |
|---|---|---|
| 首页 www.jd.com | 200 正常 | 200 正常（完整导航） |
| 搜索页 search.jd.com | 200 但移动端 errorPage"抱歉，您访问的内容不存在"（2.8KB） | **重定向 passport.jd.com 登录墙**（ReturnUrl 回搜索页） |
| 商品页 item.jd.com | 未测 | **重定向 passport.jd.com 登录墙** |

- 桌面端大陆 IP 形态与 VPS 不同（VPS 是 risk_handler 风控页 / JS 空壳），但结果相同：**搜索页与商品页均强制登录**，非价格元数据的 curl_cffi 路径在桌面端同样需要登录态
- 结论：京东无登录态不可采集；要数据仍走「登录态 cookie + 大陆 IP」或第三方聚合 API，不再重测
