# 天眼查 / 爱企查 / 企查查 / 国家企业信用信息公示系统（大陆工商背调源）

> 实测日期：2026-08-09（VPS，出口 IP 中国香港）。结论分层：**VPS 全部不可达（地域封锁）；桌面端（大陆网络）可直接访问。**

## VPS 环境实测（2026-08-09，curl 基线 + Camoufox 真浏览器）

| 站点 | 裸 curl | Camoufox 浏览器 | 墙的类型 |
|---|---|---|---|
| tianyancha.com | HTTP 419 | 明确页面："根据相关法律法规，当前所在地区暂不支持访问，当前地区：中国香港" | **地域封锁（geo-block），非反爬** |
| aiqicha.baidu.com | HTTP 000（连接重置） | NS_ERROR_NET_RESET（服务端主动掐） | 数据中心 IP 拒绝 |
| qcc.com | HTTP 200 但跳"海外产品使用"页（5KB 空壳） | — | 海外 IP 跳转 |
| gsxt.gov.cn | HTTP 521 | — | CF 拦 |

## 判断要点

- **地域封锁 ≠ 反爬**：TLS 白名单（Camoufox 级）也打不穿，墙在 IP 地理定位层
- 付费 API（天眼查/企查查开放平台）和大陆代理都花钱 → 用户原则排除

## 桌面端（BoenMind 本机）

- 用户本机是大陆正常网络 → 天眼查/企查查/公示系统**可直接 curl/浏览器访问**，不需要任何引擎
- 重测后把结果更新到本笔记（记录具体站点的可达性/反爬形态）

## 可行的免费替代（海外/香港 IP 场景）

- 香港公司注册处查册（ICRIS）——航运业务很多主体是 HK 公司，对口
- 新加坡 ACRA 免费基础查册
