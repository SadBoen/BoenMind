# ADR-0039: 阶段二候选产品面处置（壳扩展 / 协作网格 / 权限分级 / Surface 插件化）

- 状态: Accepted（2026-09-11，一次性处置余下候选与远期项）
- 日期: 2026-09-11
- 关联: ADR-0005（万物皆插件）、ADR-0009（部署与 Surface）、ADR-0010（第三方模型网关）、ADR-0020（内置能力冻结）、ADR-0030（审批裁决后台化）、ADR-0031（Agent v0.2 通信面）、ADR-0034（插件协议 SDK）、issue #31/#43/#45/#46/#53/#59

## 背景

以下 Issue 长期 OPEN，各自卡在**产品决策**或**前置工程**而非实现工作量。按「未结事项唯一入口 = Issues，架构铁律唯一查重清单 = decisions.md」，需要一次性给出裁决，避免继续以「待设计」悬置：

- **#43 MCP 权限分级**（部分免审批/免门控/时间窗口）：`deferred`（用户 2026-09-02 拍板后置）。ADR-0030 已落 session 级；本条范围是绑定级免审批与时间窗口，属审批模型扩展。
- **#45 Agent v0.2 通信面批次 2 / #31 成员级 max_concurrent_tools**：ADR-0031 已落批次 1（公告栏）；批次 2 = 点名消息 + 成员身份面（`worker` principal 加成员段）+ 成员级并发计点，三者须同步。
- **#46 W 系列壳前端浏览器扩展版**：Vite SPA 移植为 Chrome/Edge 扩展，门户回环地址 + service worker。
- **#53 hermes-webui 参考池**：产品交互面借鉴清单（非交付物）。
- **#59 残余-5 Surface 插件化**：`bm-surface-http` 路由硬编码 + `AdminConfig` 强耦合，面替换成本≈重写。

## 决策

1. **#43 维持 deferred，不因「一气做完」翻案**。ADR-0030 的 session 级模式（ask/plan/yolo，服务端记）已覆盖会话粒度免审批诉求；绑定级免审批/时间窗口是**审批模型扩展**，须先有「哪些能力值得长期免审批」的真实使用数据，且属用户 2026-09-02 明确后置项——尊重原裁决。
2. **#45 批次 2 / #31 维持 OPEN（deferred，待前置成熟）**。批次 2 的结构面（点名信封、成员字段、per-member 账本/审计归因）可实施，但其验收依赖**真并发**：当前 Runtime 是单写者 World 串行命令，`autorun` 每 task 单在途，**无任何多成员并发路径**，成员级 `max_concurrent_tools` 无场景可验。前置条件 = 新的 testkit 并发夹具（通过单写者交叉派发多成员在途）；达成后再按 ADR-0031 排批。不提前实现无场景可验的并发上限。
3. **#46 维持 OPEN（产品级，不实施）**。扩展形态的真实工作不在构建配置而在产品决策：扩展源（`chrome-extension://`）到回环后端的跨源 cookie/CORS、`host_permissions` 范围、门户与会话认证在跨源下的行为、以及分发信任。零扩展骨架，须立项出规格后再动，不属本批工程债。
4. **#53 关账（按条路由后销单）**。参考池非交付物：条目 1（审批四级）→ #43；2/4（会话管理面、交互细节）→ webapp 日常演进（W 序列）；3/5（CLI 会话桥、分工哲学）→ #46 立项时消化。无剩余实体待办，关闭并保留文本于 git 史。
5. **#59 残余-5 Surface 插件化 = 远期评估项，不立项**。当前「万物皆插件」由 MCP 一族兑现（ADR-0005/0034）；面的可插拔需先有**第二个面**的真实需求才有评估依据（ADR-0009 部署形态既定）。登记为方向性备选，不预先抽象。
6. **#59 本批收口声明**：残余-1 → ADR-0036；残余-2 → ADR-0037；残余-3 → ADR-0035；残余-4 已完成（`ff30e1c`）；残余-5 → 本条。ADR-0032 排除的双状态机项至此有归属。

## 后果

- 余下 OPEN 项均有明确裁决与前置条件，不再是「待设计」悬空态；本批关闭 #53，维持 #31/#43/#45/#46 OPEN 并附裁决评论。
- 「一口气做完」的边界被诚实划定：可实现的工程债（#36/#39/#55/#59/#60）本批实施；产品/前置未成熟项不伪装完成。
- Surface 插件化若将来立项，触发条件 = 出现非 HTTP 的第二面或面替换的真实需求，届时另发 ADR。
