# ADR-0015: 文档体系整理——熔入式修订与三层附页

- 状态: Accepted(2026-09-01,用户委托的文档整理轮)
- 裁决人: 用户(全权委托,见当轮会话;机制细节由 AI 拟定)
- 关联: ADR-0008(模型即代码)、AGENTS.md 硬纪律 3、基线头部「维护规则」

## 背景

2026-09-01 文档对齐审计发现,近三周的快速迭代在文档层留下系统性补丁堆积:

1. **基线(BoenMind-CORE-ARCHITECTURE.md)25 处「ADR-000N 增补」引注块**挂在正文之后,
   同一规则新旧两版并存;多处补丁内嵌的行号引用(「第 141 行」「第 776 行」等)已漂移失效;
   §1.1 非目标同段自相矛盾(原文「无远程访问」vs ADR-0009 增补);§8.4 已废止的
   「仅升级前创建快照」在 §13.7 仍留残句;§15 ASCII 拓扑过时;§18 停在 M8;
   §23 缺 ADR-0012 归档行。
2. **AGENTS.md 混装三类内容**:现行规则、历史进度流水(20+ 条内联裁决追记)、
   操作踩坑;文件地图缺 apps//shell//scenarios/ 等真实目录,残留旧路径 web/src-tauri。
3. **索引滞后无主**:adr/README 缺 4 条;35+ 条未闭合遗留散落在 9 个回看 §6、
   FULL-REVIEW §4、AUDIT F 系、PENDING 后续方向四处,没有单一「还欠什么」入口;
   milestones/ 34 个文件无目录导航。

## 决策

1. **熔入式修订(取代追加式引注块)**:ADR 对基线的修订直接改写正文对应段落,
   原地标注 ADR 编号(如「回退边界(ADR-0003):…」);不再新增 `> **ADR-000N 增补**`
   引注块。本轮已将既有 25 处全部熔入,失效行号引用清除。基线 §1-§24 编号是
   adr/、milestones/ 的引用锚点,**编号骨架冻结**;重排结构前必须 grep 引用面。
2. **AGENTS.md 只装现行规则**:定位/当前状态(一行)/文件地图/工作流/硬纪律/
   工作方法/环境指针/最高频坑。历史进度、踩坑细节全部迁出。
3. **三层附页**(新建):
   - `milestones/HISTORY.md` — 交付时间线,append-only(唯一进度真源,其他文档不复刻);
   - `milestones/BACKLOG.md` — 未结事项总台账(掉链项/后置项/前置项/审计 F 系/
     文档欠账,唯一「还欠什么」入口;回看收官时增改,完成改 DONE 不删行);
   - `PLAYBOOK.md`(根) — 实操备忘与踩坑清单(环境变量/前端四坑/浏览器怪癖/废止速查)。
4. **milestones/README.md** 作为里程碑目录导航,明文确立 W 序列「验收入规格、
   不另立 review」惯例(追认 W2 §7 / W3 §6 的既有做法;W4 验收待回填入 BACKLOG)。
5. **进度记录职责收口**:基线 §18 只保留里程碑定义与通过条件;交付状态只在
   HISTORY 与 git;AGENTS.md 只留当前状态一行。deepwiki S1-S10 裁决状态从
   architecture/README 摘除,统一由 BACKLOG 台账维护。
6. 不动的东西:boenmind-contracts 合同库(冻结)、M/W 各规格与回看正文(历史记录)、
   既有 ADR 语义、architecture/boenmind.c4(C4 回写=F-06,仍是下一批开工前置,
   本轮只在基线 §15 如实标注漂移台账指针,不擅自改模型)。

## 后果

- 文档增量从此有唯一去处:裁决→新 ADR;基线修订→熔入;进度→HISTORY;
  欠账→BACKLOG;操作经验→PLAYBOOK。「哪里该写什么」不再自由发挥。
- 基线读感恢复「稳定结论」定位;补丁式引注块从机制上灭绝。
- 已知代价:熔入后基线段落不再逐一保留 ADR 原文措辞,考据以 adr/ 文件为准
  (§17.1 已注明);历史引注块的原文可在 git 历史(本 ADR 提交前的版本)找回。
- 登记 BACKLOG §5 的文档欠账(api_dsh 删除待追认、MCP 示例配置命令不实、
  release.yml 注释、webapp 测试缺位、坏 MCP 条目拒启)按台账推进,本轮不处理。
