# ADR-0009 部署形态与 Surface 策略:VPS 托管、Web/TUI Surface、Windows 桌面壳

- 状态: accepted-with-conditions
- 日期: 2026-08-29
- 决策类型: 产品形态裁决(含一项冻结非目标的受限解除)
- 来源: 用户产品决策(2026-08-29);按 §1.1 非目标解除程序(先检查合同与扩展点)执行

## 背景

用户要求:① CLI 要有交互式 TUI(彩色、可交互,对齐主流 AI CLI 的形态);② Runtime 跑在
自管 VPS 上、经网页访问;③ 桌面只出 Windows 壳(不做 Linux/macOS 桌面);④ 网页前端与
Tauri 桌面壳共用同一套前端代码。

冲突点:§1.1 冻结非目标含「无远程访问」。解除程序检查结果:Wire API 传输无关(合同只
定义信封与负载)、事件持久化 + 游标重连(resume_cursor)、Surface 可插拔(L5)——扩展点
全部原生支持远程网页访问,不破坏任何已冻结合同;新增的是安全要求(网络暴露),不是
合同变更。故准予受限解除。

## 裁决

1. **部署**:阶段一支持两种等价部署——本机单进程、自管 Linux VPS 单进程;Runtime 默认
   headless。状态单一权威始终在 Runtime 侧,访问端(Surface)无状态,因此不构成多设备同步。
2. **非目标受限解除**:「无远程访问」→ 允许单用户经 TLS + 个人令牌/passkey 的网页访问
   自管 VPS;无账号体系、无多用户、无移动端等其余非目标不变。
3. **Surface 矩阵**:CLI(脚本模式 JSON/JSONL + 交互式 TUI)与 Web UI 为阶段一交付
   Surface;Tauri 仅作 **Windows** 桌面壳,复用 Web 前端同一代码库;不做 Linux/macOS 桌面壳。
   TUI 是 CLI Surface 的交互呈现形态(`watch`/审批面板),不是新合同层——主流 AI CLI
   (Claude Code/Gemini CLI 等)即此形态。
4. **安全前置**(进 M3 传输合同):TLS 1.2+;单用户令牌或 passkey,失败限速与会话可失效;
   Surface 鉴别事件入审计;威胁模型增补 T-13/T-14。
5. **里程碑落点**:M3 锁定 HTTP + SSE/WebSocket 传输与鉴权合同,交付交互式 TUI 起步版;
   Web UI v1 与 Windows Tauri 壳在 M8(首批真实 App 与发行质量)交付。

## 条件与验收

- T-13/T-14 写入威胁模型并配套测试(未授权访问被拒、令牌可失效)通过之前,不得启用任何
  公网监听(M3 验收项)。
- Web UI 与 Tauri 壳共用同一前端代码库,禁止分叉(分叉 = 双倍维护,违背单一真源)。
- VPS 部署方式文档化:反向代理 TLS 或内建 TLS,二选一。

## 后果

- 正面:Surface 可插拔架构的价值兑现;前端一次编写、网页与 Windows 壳两处运行;
  VPS 场景下「断线重连、界面关了活照干」本来就是本架构的验收项,天然成立。
- 代价:信任根从「本机 OS 账户」扩展为「用户对 VPS 的控制权」+ 网络边界,安全门槛提高
  (见威胁模型 T-13/T-14 与审计要求)。
- 基线 §1.1 非目标清单按本 ADR 增补段修正,其余非目标不变。
