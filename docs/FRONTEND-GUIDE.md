## 0. 技术栈与变量所有权（必须先读）

- **React 19 + TypeScript + Vite 8 + Tailwind v4 + daisyUI 5**；不用 dockview。
- **通知：sonner**（右下角 toast，见 §4.5）。
- 布局：**自建 Unit 单元 + react-resizable-panels**。
- **CSS 变量所有权（10 行，防止主题花）**：
  ```css
  :root {
    /* ① 尺寸 token（本文件专属）——永远不随主题改 */
    --char-ht: 16px;
    --hairline: 1px;            /* 唯一允许的非阶梯例外 */
    --space-1: 10px;            /* 由 0.618×16 取整 */
    --space-2: 20px;
    --space-3: 30px;
    --radius-sm: 10px;
    --radius-md: 20px;
    --radius-pill: 9999px;      /* 全圆，唯一例外 */
    --font-sm: 12px; --font-ui: 14px; --font-body: 16px;  /* 字号三档例外 */
    --control-h: 48px;          /* 3×字高：按钮/输入框/rail/状态栏/composer foot 统一 */
    --nav-w: 48px;              /* = 3×字高 */
    --session-w: 288px;         /* 会话栏 = 18×16 整数倍 */
    --session-min: 224px;       /* = 14×16 整数倍 */
    --file-tree-w: 280px;
    --editor-w: min(100%, 60vw); /* 编辑区默认 = 0.618×A4 ≈ 490px，用 min 兜窄屏 */
    --msg-max-w: 960px;
    --status-h: 48px;
    --composer-foot-h: 48px;
    --composer-top-h: 64px;     /* 2×foot，textarea 高区 */
    --density: 4px;             /* 4 的幂次间距（4/8/12/16）走 8 的幂次即可，此处为最小格 */
  }
  /* ② daisyUI 主题语义色：由 data-theme 覆盖，组件只引用 daisyUI 变量 */
  /* ③ 组件代码内禁止写 hex/px 字面量——全部引用上述 token */
  ```
- **尺寸规则（务实，放弃"任何数×0.618"宗教）**：
  - 间距/尺寸阶梯 = `--space-1/2/3`（10/20/30）与 4 的幂次；栏宽/控件高用字高**整数倍**或语义 token。
  - **`--hairline: 1px` 是唯一允许的裸像素例外**（分割线/边框）。
  - 圆角只允许 `--radius-sm / --radius-md / --radius-pill` 三档。
  - 字号只允许 `--font-sm / --font-ui / --font-body` 三档。
  - 全文禁止再出现 `8px / 14px / 220 / 240 / 280 / 490 / 640 / 960` 等裸数字。

## 2. 文件 dock：唯一入口 + 两层收起（无任何「或」）

- **入口（唯一）**：聊天视图 topbar **右侧**一个「文件」按钮。**非聊天视图（编程/WIKI/设置）不挂文件 dock。**
- **两层收起**（都走命令式，不用拖拽收到底）：
  - 文件 dock 整体：点 topbar「文件」按钮 `collapse()/expand()`；`minSize=224px`（换算成百分比或库像素 API），**永远不拖到 0**。
  - 编辑区：点目录树顶部的抽屉图标，收起/展开右侧编辑区（§5.3"抽屉图标"）。收起时目录树独占 dock。
- **`minSize` 与 react-resizable-panels 的接法（必须写死）**：该库 `minSize` 为 **0–100 百分比**。包装约定：`UnitPanel minWidthPx={224}`，内部用 `minSize = minWidthPx / 容器宽 × 100` 换算；**禁止直接把 px 传给 `minSize`**。收起只走 `panelRef.collapse()`（不 unmount）。
- **侧栏语义**：会话栏、文件 dock 只 **collapse（保持挂载）**，不 unmount。设置页不走这套（设置是主区视图切换）。

## 3. Unit（单元基座）

```tsx
<Unit
  title="会话"                 // 顶栏标题
  actions={<span>…</span>}    // 右侧动作槽（收起/文件按钮等）
  collapsed={collapsed}       // 受控：收起态
  onToggleCollapse={…}        // 收起/展开回调（命令式，不拖到底）
>
  {children}
</Unit>
```

- **收起只用 `onToggleCollapse`（命令式 collapse/expand），禁止拖拽收到底**（拖到 0 后找不到分割线）。
- `minWidthPx` 由外层（Workspace）给定；内部换算成面板百分比。收起宽度 = `minWidthPx` 变体（或 0），但**分隔线永远可见可拖**（不允许 0）。
- 单元不绑布局库，外层 flex/panel 编排。样式全走 token。

## 4. 聊天界面

### 4.1 布局（已在总图内，会话栏细节）

- **topbar**：左 `☰` 抽屉按钮（会话栏显示/收起开关）；中/右 = 视图标题（会话标题）；**不显示模型名**（模型名只在 composer 模型下拉、助手消息 msg-role 头）。右侧放「文件」按钮（§2 唯一入口）。
- **会话栏**：顶部固定 **① 新建会话（胶囊）→ ② 搜索框 → ③ 列表**。
  - 列表日期分组：**中文文案**（今天 / 昨天 / 更早），不用英文 Today/Yesterday。
  - 每条 = 标题 + 预览 + 时间；hover 露出 `⋯` 菜单：**重命名 / 归档 / 删除（带确认弹窗）**。
  - **tag 闭环（需求 v2 铁律，必须完整实现）**：
    - 「⋯」菜单含「设置标签」（可选多个 tag）；
    - 会话栏顶部 tag chip 过滤条：点击 chip = 过滤出含该 tag 的会话（多选 = 并集）；点已选 chip = 取消；
    - 无匹配 → 空态一行"没有带此标签的会话"；
    - 归档会话默认不进列表（可在设置或「⋯」中恢复）。
  - `minSize=224px`（`--session-min`），`autoSaveId` 记宽；**禁止拖到 0**。
- **消息区**：文本流居中 `max-width:960px`（`--msg-max-w`）。
- 窄屏：会话栏 slide-in 抽屉 + 遮罩。

### 4.2 消息层级（硬规则）+ 缺失交互补齐

1. **用户消息** → 右对齐气泡 + 头像（占位图标 A，最右端）：
   - 气泡 `max-width:60%`（窄 78%/90%）、**圆角 = `--radius-sm`**、强调色底 + `--color-primary-content` 白字。
   - "窄"断点：**<640px**（全局唯一断点）。
2. **助手消息** → 左对齐、prose-first、无重气泡 + 头像（占位图标 B，起始处）：
   - 正文 **`--font-body`（16px）**、行高 1.75；`msg-role` 头：模型名 + 时间戳（hover 显全日期）。头像与 role 头同行/紧邻。
3. **工具调用 / 过程** → 可折叠元数据行（图标+名称+摘要，可展开）。
4. **推理卡片**（thinking）：
   - 折叠态：`思考中… / 思考完成 · Ns + 🧠 + chevron`，无边框弱字色。
   - **折叠时摘要 = 取 thinking 首行/前 N 字**（前端启发式，**不是**再调模型生成）。
   - 展开态：整段推理 Markdown；**流式期间 `<pre>` 纯文本追加，stream 结束后一次性转为 Markdown**（避免重解析抖动）。
   - **显示偏好存设置「外观」**：`auto（默认，来推展开、完事收起为摘要）/ expanded / hidden`；**v1 只做这 3 档**，砍 summary 单独档。手动点过 = 本条消息不再受 auto 覆盖（直到新消息开始）。
5. **上下文压缩 → 居中分隔线**（`上下文自动压缩` 中文）。
6. **流式性能**：rAF 节流 + live 期关 transition + `content-visibility:auto`。
7. **必补交互（v1 不得省）**：
   - **Stop**：流式/生成中发送钮变成 **Stop**（点=终止流）；不再禁发送钮。
   - 助手消息 hover：**复制 / 重试 / 编辑用户消息**。
   - 空会话空态；历史加载中骨架；流断/重连提示（toast.error）。
   - 附件：消息内显示为 chip（文件名+大小+可移除）；附件本身在 v1 若后端不支持则只放 chip 占位，但交互要有。

### 4.3 Markdown

- 管线：react-markdown + remark-gfm + **highlight.js**（代码高亮）。**KaTeX / mermaid v1 不引入**（留接口，默认 gfm + 高亮）。
- 代码块：角标头部（语言名）+ 复制（"Copied!" 1.5s 后复原）；圆角 `--radius-sm`。
- 表格 `--font-sm`；长表横向滚动。
- **聊天消息不清洗**（后端保证 HTML 不进消息流）；**文件预览必须 sanitize**（§5.4）。

### 4.4 Composer（foot line 常驻）

```
┌──────────────────────────────────────────┐
│  textarea（auto-grow，上限 8 行）          │
│──────────────────────────────────────────│
│  [附件][收藏] | [模型▾][推理▾]            │
│                     [发送 / Stop]         │
└──────────────────────────────────────────┘
```

- 外壳圆角 `--radius-md`、1px 边（hairline）、focus-within 强调边框 + 光晕。
- 上栏 auto-grow **textarea 高 ≤ 8 行**（不是 240px）。
- **下栏 foot 高 `--composer-foot-h`（48px）**：左=附件/收藏占位；模型下拉；推理档位（off/low/medium/high）；发送圆钮（空=禁用）/ Stream 中 = **Stop**。
- **用量环不在 composer**（只在 statusbar，全局唯一）。
- 审批/运行状态卡：**v1 不画审批卡**（需求阶段不实现），删除 composer 那句残留；（将来加时再补最小状态机）。

### 4.5 右下角 toast（sonner）

- `Toaster` 挂根，`position="bottom-right"`。
- 自动消失：成功/信息 ~4s；失败 ~6s；加载持续到完成。
- **颜色走 `--color-success / --color-error`**（不要锁死绿/红字面——卡通皮肤成功色可能不是绿）。`style` 里 `--normal-bg/--normal-text/--normal-border` 引 token。
- 图标：对勾圆 / 叉 / `i` / 转圈；跟随主题。
- **去重 / 上限**：同一消息 1s 内不重复弹；最多同时 3 条（超出排队）。

- **聊天视图右侧 dock**，topbar「文件」按钮进/出；非聊天视图无文件 dock。
- 布局 = 目录树(280px 可收起) | 明文编辑区（默认 0.618×A4 ≈ 490px 可用 `--editor-w`）。

### 5.2 布局

```
┌────────────┬──────────────────────────┐
│ 目录树      │  编辑器 / 预览           │
│ (280px,    │  （明文编辑区 490px）     │
```

### 5.3 目录树（左栏）

- 树：文件夹递归可折叠、可排序；当前项高亮；文件类型小图标。
- **右键菜单**（唯一文件操作入口）：新建文件夹 / 上传 / 下载 / **复制路径** / 重命名 / 删除。**下载/复制路径只在右键菜单，无工具栏按钮**（需求 v2 铁律）。
- **删除带确认**（toast 反馈成功/失败）。
- 上传：右键「上传」或拖拽到树（Tauri 用文件对话框；浏览器 file input 降级）。

### 5.4 明文编辑区（右栏）

- **双击文本文件 → 右侧打开**，明文可编辑。
- 顶栏：文件名（路径）+ 脏标记（未保存 `•`）+ **保存**（Ctrl+S）；保存调后端写回，失败 toast.error 不静默。

- 非文本：图片只读预览；二进制"无法预览"。
- **安全**：文件预览内容**必须 sanitize**（与聊天相反）。

## 6. 设置界面（框架）

**形态**：点击 rail 底部「设置」齿轮 → 主区切换设置单元视图（不是 modal/抽屉）。

### 6.1 结构（v3 定稿）

```
┌──────────────────────────────────────┐
│  设置 (单元标题)                       │
│ ┌────────┬─────────────────────────┐ │
│ │通用    │                         │ │
│ │模型    │   内容区                 │ │
│ │外观    │   （当前分区整页）        │ │
│ │账号    │                         │ │
│ ├────────┤                         │ │
│ │SKILL   │   （SKILL/插件 = 独立分区， │ │
│ │插件    │     内容区整页表格）       │ │
│ └────────┴─────────────────────────┘ │
└──────────────────────────────────────┘
```

- **左导航约 200px**（`--space-2` 级），border-right。
- 分区：**通用 / 模型 / 外观 / 账号 / SKILL / 插件**（SKILL 与插件各为独立分区，**不是**钉在每个设置页下半的表）。
- **声明式注册**（核心需求）：
  ```ts
  interface SettingsSection {
    id: string; label: string;
    icon?: ReactNode; order?: number;
    component: LazyExoticComponent<...>; // 懒加载（点击才挂载）
  }
  // 插件 registerSection()
  ```
  框架只管「导航渲染 + 当前分区懒加载」，不关心内容。
- **交互**：导航点选 → 懒加载该分区（切换卸载上一个）；高亮当前；**v1 不做 `?settings=` URL**（无路由，rail 视图状态是 source of truth）。
- **数据**：暂存 localStorage；接后端后 `settings.get/set`。
- **表单原语（必须抽，否则每分区一套样式）**：`SettingsForm` 提供 Row / Toggle / Select / Text / Password——全走 `--control-h` 高 + `--radius-sm`，禁止每分区自创输入样式。

### 6.2 SKILL / 插件分区 = 整页表格（独立页，不是下半表）

- 内容区整页 = 一张表（SKILL 分区列 SKILL；插件分区列插件，**两分区各一张不混表**）。
- **搜索栏**：顶部，按名称过滤。
- 表列：**名称 | 类型 | 操作**（操作=卸载 ×、设置 ⚙）。
- **卸载**：点击 → 确认弹窗（`确认卸载 <名称>？`）→ 确认才执行 → toast 反馈。
- **设置**：点击 → **居中 modal**（带关闭按钮），窗内是该 SKILL/插件的配置（复用 SettingsForm）。
- 内置 item：**卸载禁用**（灰态）或隐藏卸载；只有第三方可卸载。
- **空态**：无搜索匹配显示"没有匹配的 SKILL/插件"。
- 行 hover 高亮；行分隔走 hairline。

### 6.3 内置分区最小内容

- **通用**：语言、界面字号档位（三档，改 `--font-*` 不缩放结构）。
- **模型**：默认模型选择、推理档位默认值。
- **外观**：**风格（现代/卡通）× 材质（纯色/毛玻璃）两轴**（见 §7）+ 背景类型。
- **账号**：密码登录设置；**v1 未装配鉴权 = 隐藏入口**（整分区显示"鉴权未启用"，不假装已交付）。
- **登录（v1 明确）**：本版 **不做鉴权 v1**——不实现登录界面；但**预留**：装配鉴权后应显示启动全屏登录（密码框+进入，失败 toast.error），设置里可改密。文档标注为"鉴权启用后"分支，不阻塞 v1。

## 7. 主题：两轴正交（改正互斥三预设）

需求 v2 §3.1：三档 = 「卡通↔现代」×「纯色↔毛玻璃」**两个正交轴**。

- **设置 → 外观 → 两个独立 control**：
  - 风格轴：`现代 / 卡通`
  - 材质轴：`纯色 / 毛玻璃`
- **「黑白档」= 现代 × 纯色 的默认配色**，是轴上的一个点，**不是**第三档。
- 材质 token：`--surface-bg / --surface-panel / --surface-float`——毛玻璃档加 `backdrop-filter` + 透明；纯色档不透明。卡通档 = 卡通贴纸语汇（图标/装饰），**不是加毛玻璃**。
- **背景类型**：`纯色 | 图片`；**动态 v1 砍掉**（或只做"图片"档，视频/动效禁止）。**任何档都禁止 CSS 渐变背景**。
- 切换只改 CSS 变量 / `data-theme`，组件不感知。

### 7.1 黑白档（默认）视觉语言【frontend-design 定稿】

> 这是「现代 × 纯色」这个默认点在落地时**具体长什么样**——不是第三档，是轴的默认取值。实现者必须按此渲染；卡通/玻璃档留 token 位即可。

#### 配色（4–6 个命名色 + 语义）

```css
/* 基底三个中性（不是纯白纯黑，是偏纸感的灰阶，抵消"后台管理系统感"）： */
--ink-900: #1f2328;        /* 主文字（近黑偏蓝灰，不是 #000） */
--ink-600: #57606a;        /* 次级文字 / 弱强调 */
--ink-400: #8b949e;        /* 辅助/占位符、时间戳 */
--paper-0: #fbfbfa;        /* 窗口基底（离线米白，比纯白暖 4%） */
--paper-1: #f3f3f1;        /* 侧栏/面板（较基底深一档，同色系） */
--paper-2: #e9e9e6;        /* 悬停/选中底、输入框底 */
--accent: #3b82f6;         /* 单一强调色——用户气泡/主按钮/当前 rail/选中（仅此几处） */
--accent-content: #ffffff; /* 强调色上的文字/图标 */
--success / --error: 语义绿 / 红（走 daisyUI 变量，不锁死品牌绿）
```

- **强调色只用 3 处**：用户气泡底、主按钮/当前 rail、选中态。其余一律中性。
- **层级**：窗口 = `paper-0`；面板/侧栏 = `paper-1`；输入/悬停 = `paper-2`。三级递进，不要四、五级。

#### 字体（系统栈，无 webfont）

- 界面 + 正文：`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`（Windows/macOS/中文兜底）。
- 等宽（代码/路径/时间戳）：`ui-monospace, "SF Mono", "Cascadia Code", Consolas, monospace`。
- 权重基调：标题 600、正文 400、辅助 400；**不引入黑体/超细**（保持中性克制）。

#### 布局气质（与 §1 的克制一致）

- 转录区零阴影；只有浮层（menu/modal/toast）有极轻阴影（`0 1px 3px rgba(0,0,0,0.06)`）。
- 以 hairline 分割（1px）组织层级，**少用大面积背景色块**。
- 圆角三档（sm 10 / md 20 / pill），默认元素走 sm，卡壳走 md，不用圆角做装饰。
- 留白密度：列表/表单用 `--space-1/2`；段落 `--space-2`；大区 `--space-3`（克制，不铺满）。

#### 签名元素（本产品可被记住的那一个点）

**「状态即光线」**：整个界面平时是安静的中性纸感；唯一会"发光"的是**活动状态**——流式生成时光标/发送钮有一条极细的强调色呼吸线（`--accent`），工具执行时卡片左缘一个 2px accent 竖条，toast 用语义色点亮。**强调色只在"有东西在动/在发生"时亮起，静默时全界面是灰阶。** 这就是"黑白"档的名字由来的现代诠释——不是苍白无聊，而是用光来标记生命。

- 落地：流式时消息区末光标 `caret` 呼吸动画（keyframes opacity 0.4/1，1.2s）；工具卡执行左缘 accent；当前 rail live 处 accent 底。**其余时刻无彩色**。
- 视觉纪律：呼吸动画只在流式 live 期，不常驻；live 结束立即恢复灰阶 + 关闭 transition。

#### 空态文案（frontend-design 写作规范）

- 空会话："还没有会话 —— 在左侧新建一个开始。"
- 空文件树："工作目录是空的 —— 右键新建文件夹或上传。"
- 空 tag 过滤："没有带这个标签的会话。"
- 错误用主动态："保存失败：磁盘只读。请更换目录后重试。"（不道歉、不模糊）

### 7.2 玻璃档（毛玻璃轴）视觉语言【透明分层规格】

> 这是材质轴 = 毛玻璃时的**唯一实现依据**。完整规格存档于 `.review/grok/glass-opacity-grok.md`（已评审定稿），本节为提取的关键约束 + 与 v3 的对接。**禁止第三方玻璃生成器**（css.glass 等）产出的临时值混入——参数必须来自本节打分表，不许现场发明。

#### 原则（先钉死）

1. **全应用只有一个背景**（色或图）；任何面板/侧栏/气泡都禁止自带 hue（色相）。
2. 所有「表面」共用同一层**中性黑纱** `rgba(0,0,0,α)`，用 **α 分层**，不用配色分层；另加一层恒定**白散射（霜）**模拟玻璃漫反射。
3. **禁止对包裹文字的容器写 `opacity`**（字会一起淡）——只改 `background` 的 alpha。
4. **blur 最多叠两层**：壳层一层、弹出层一层；嵌套内容（气泡/代码/卡片）**只改 alpha、不再加 backdrop-filter**，否则字糊、GPU 熔化。

#### 材料三档（不要每层自己发明）

| 档 | 用在 | `backdrop-filter` | 上沿高光 |
|---|---|---|---|
| **A 壳** | 面板 / 导航 / 侧栏 / 文件器 | `blur(24px) saturate(160%)` | `inset 0 1px 0 rgba(255,255,255,.12)` |
| **B 条** | composer / 状态栏 | `blur(20px) saturate(150%)` | `inset 0 1px 0 rgba(255,255,255,.10)` |
| **C 浮** | 菜单 / 下拉 / Modal | `blur(40px) saturate(180%)` | `inset 0 1px 0 rgba(255,255,255,.16)` + 落地影 |

#### 透明分层表（核心，α 全部来自 `--g` 滑块）

`--g` = 用户滑块（默认 `0.42`，范围 `0.20–0.95`）。结构层相对 `--g` 偏移写死；内容层固定不随滑块。

| 元素 | 角色 | 默认 α | blur | saturate |
|---|---|---|---|---|
| 全局面板底板 | 结构 | `--g` → 0.42 | 24px | 160% |
| 左侧图标导航 | 结构偏铬 | `--g + .08` → 0.50 | 24px | 160% |
| 会话侧栏 / 设置导航 | 结构 | `--g + .04` → 0.46 | 24px | 160% |
| 聊天画布 | 结构最透 | `--g * .40` → 0.17 | 20px | 140% |
| 状态栏 | 结构 | `--g + .10` → 0.52 | 20px | 150% |
| 助手气泡 | 内容，固定 | 0.72 | 无 | — |
| 用户气泡 | 内容，固定 | 0.80 | 无 | — |
| composer | 内容偏铬，固定 | 0.78 | 20px | 150% |
| 菜单 / 下拉 / Tooltip | 弹出，固定 | 0.90 | 40px | 180% |
| Modal / 命令面板 | 弹出，固定 | 0.88 | 40px | 180% |
| 工具卡 | 内容，固定 | 0.80 | 无 | — |
| 代码块 | 内容，固定 | 0.84 | 无 | — |
| 设置表单区 | 内容，固定 | 0.74 | 无 | — |
| 列表行（未选） | 嵌套 | 0（全透） | 无 | — |

- **读法**：聊天画布几乎全透、气泡自己成层（"正常全透，上去才实"）；用户泡 0.80 / 助手泡 0.72 只靠 α 不分色；菜单 0.90+40px 比主界面实一档保证字不糊。
- 悬停：结构 `min(α + 0.18, 0.92)`，内容 `min(α + 0.10, 0.94)`。
- **滑块联动**：`--blur-shell: calc(28px - var(--g) * 10px)`（越实越不需要霜）。

#### 边框 / 文字 / accent / 选区（快速约束）

- 边框全白+alpha：`--stroke .09 / --stroke-strong .15 / --stroke-weak .055 / --stroke-hover .20 / 焦点环 rgba(154,171,191,.55)`。分隔线 1px 实线，禁 2px/渐变条。
- 文字：`--fg .92 / --fg-2 .62 / --fg-3 .38 / --fg-4 .22`（白字 alpha，不写死纯白）。
- **accent 极克制**：只允许 ≤3px 的线、焦点环、主按钮、开关 ON。选 `#9AABB7`（雾蓝灰，**不是**青/电蓝）。
- 选区：不换色，三件套＝更深一档黑纱 + 更亮一档霜 + 白边；列表项加 2px accent 左条。当前 dock 面板 = 黑纱 +0.08 + `--stroke-active` + 上沿高光抬到 .18，**不加 accent 底**。

#### 设置 → 外观 → 玻璃滑块（对应需求 v2 可调能力）

- **透明度滑块**：绑 `--g`（20%–95%，默认 42%），只控制**结构层**（面板/导航/侧栏/聊天画布/状态栏/文件器/设置导航）；**内容层锁死**（气泡/composer/菜单/Modal/工具卡/代码/设置表单不随滑块）。
- **毛玻璃色彩（色调）可调**：预留第二滑块绑 `--glass-rgb` 的色相偏移（或在图里色相），v1 可先放 token 位（默认 0,0,0），不阻塞。

## 8. 硬规则（可执行的清单）

1. 同类组件永远同参（圆角/字号/间距全走 token）。
2. **尺寸规则**：见 §0 变量表。全文检索，禁止裸 px（`--hairline` 是唯一例外）。
3. 一个强调色原则；转录区零阴影（阴影只给浮层）。
4. 布局语义：一个窗口分两块、可拖，不是两个标签页。
5. 用户右气泡（带头像）/ 助手左 prose（带头像）/ 工具与思考降级为元数据行。
6. 流式 rAF 节流，live 期关 transition。
7. 会话分类用 tag 不用 workspace（含打 tag/过滤/空态闭环）。
8. 侧栏/单元设最小宽度，分割线禁止拖到 0；收起靠 topbar 按钮命令式。
9. 设置声明式可扩展；SKILL/插件=独立分区整页表格 + 搜索 + 卸载确认 + 设置居中 modal。
10. 文件操作（下载/复制路径）只在右键菜单；文件预览必须 sanitize。
11. 编辑区默认 0.618×A4（`--editor-w`）；其显示/收起由目录树顶部抽屉按钮控制。
12. toast（sonner）走 `--color-success/error`，跟随皮肤，不锁死绿/红。
13. 禁止渐变背景（任何档）。
14. **签名视觉（黑白档）**：活动状态才亮强调色（流式光标呼吸 / 工具卡左缘 accent / 当前 rail）；静默时全界面灰阶零彩色；呼吸动画只 live 期，结束即恢复。
15. **玻璃档**：透明分层约束见 §7.2（黑纱 α 分层、blur 最多两层、内容层不随滑块、accent 只用 #9AABB7 ≤3px）——**禁止用第三方玻璃生成器临时值**。
16. 窄屏（<640px）侧栏/单元成抽屉 + 遮罩。
17. 桌面壳（Tauri）能力浏览器下优雅降级。

## 9. 交付顺序（一口气写完，token 先行）

> **实现纪律**：一旦开工**整个前端一口气写完不中断**。不是排版清单的 12 步，而是**代码内连续推进**。**token 表在第一步就写进代码**（不是第 11 步），否则必现裸 px。
