## 2. 本轮修复的关键真 bug（勿回退）

- **EventBus Disposer 即弃**：`attach_event_bus` 原 `let _ = on_event(...)`，Disposer drop 即注销，
  实时事件从未进 broadcast。现返回 Disposer、main 持有。
- **wire seq 错误**：原 `record.seq - 1`（SessionStarted 不翻译但占 record.seq，产生 seq 重叠），
  前端 dedup 丢全部 live 帧。现按会话累计翻译成功事件数（与 translate_events 一致）。
- **error 形状缺 details**：`{ok:false,error:{code,message}}` 缺 `details`，前端 zod 校验失败
  （"无法打开文件夹"弹窗根因）。现恒带 `details:{}`。
- **SessionRecord 加 session_id 字段**（bus 全局不按会话过滤，监听方据此路由；持久化只存 event 不受影响）。
