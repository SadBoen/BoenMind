# WIKI 应用设计（xu-wiki → BoenMind 迁移）

日期：2026-08-17 · 状态：已落地（待用户便携包实测）

## 背景与拍板点

用户将自有项目 [SadBoen/xu-wiki](https://github.com/SadBoen/xu-wiki)（Python CLI 的关系驱动
Wiki 引擎）迁移为 BoenMind 的 WIKI 应用。四个拍板点（用户确认）：

| 拍板点 | 决策 |
|---|---|
| 引擎路线 | **Rust 重写**（bm-wiki crate，无 Python 依赖） |
| M1 范围 | 核心闭环（建库/浏览/检索/Page/学习层/关系），相册/doctor/多 wiki 后置 |
| 界面形态 | 三栏（树 / 阅读编辑 / 关系对话） |
| 聊天集成 | 场景会话 + 工具（wiki_* 三件套进 wiki 会话工具面） |

## 架构

```
frontend (React 三栏)                 backend
┌───────────────┐   /api/wiki/*   ┌──────────────────────────┐
│ WikiApp        │ ──────────────▶ │ routes/wiki.rs (REST 面) │
│  WikiTree      │                 ├──────────────────────────┤
│  WikiReader    │   wiki_* 工具   │ wiki_tools.rs（场景工具） │
│  WikiEditor    │ ◀────────────── │   ├ 注册：bm_engine 场景  │
│  WikiMeta(关系/对话)│             │   └ 执行：compat_engine   │
└───────────────┘                 ├──────────────────────────┤
                                  │ bm-wiki crate（引擎核心）  │
                                  │  frontmatter/nodes/splitter│
                                  │  relations/query/ingest/  │
                                  │  layers/store             │
                                  └──────────────────────────┘
```

- **库位置**：`working_dir/wiki/`（随工作目录/便携包随身）
- **存储格式**：与 xu-wiki 完全兼容——`nodes/{pages,lists,reports,entities}/{node_path}/{slug}-{uid}.md`
  纯 Markdown + YAML frontmatter（字段名对齐 xu-wiki constants.py），既有 xu-wiki 知识库可无缝打开
- **检索**：ignore::WalkBuilder（Ripgrep 库族，尊重 .gitignore）+ regex 固定串忽略大小写；
  打分 = 标题命中×5 + body 命中 + 层权重（Entity=2/Report=3/List=1/Page=0）
- **关系**：frontmatter `relations` 字段 50 边 LRU（进队首/命中前挪/满 50 弹尾）
- **Page 不可变**：GUI 无编辑入口；修订走 patches 通道（API POST /api/wiki/node/{uid}/patch）；
  学习层（List/Report/Entity）可改（PATCH）
- **Report 强制证据链**：references ≥1（BAN-ARCH-5）
- **场景工具**：`wiki_query` / `wiki_ingest` / `wiki_add_relation` 只在 session.app == "wiki"
  会话注册（bm_engine.rs 场景注册点，2026-08-16 预留位）；4-key JSON 信封 `{status,data,message,hints}`

## REST 面（/api/wiki/*）

status / create / tree / node{GET,PATCH} / node/{uid}/patch / ingest / query / expand /
relations{GET,POST,DELETE} / lists / reports / entities

## 前端三栏

- 左：检索框 + 四分区树（Pages/Lists/Reports/Entities，折叠分区）
- 中：阅读（prose Markdown + 元数据头 + 成员/证据区）/ 编辑（textarea + 预览切换，Page 只读）/
  检索结果（打分排序）
- 右：Tab 叠放【关系（LRU 列表 + 添加/删除）/ 对话（ChatPane panel + scene="wiki"）】
