## 2. 关键设计决策与坑（勿回退）

- **mock 默认**：`--config` 缺省不装真 provider——M2.5 行为、gate25/conformance 轨迹、CI 全不变。
- **单一 LlmPort 保持**：`LoopRuntime` 仍持单一 `Arc<dyn LlmPort>`，多 provider 由
  `MultiProviderLlm` 聚合；会话选择经 `ReactLoopAgent::set_model_override`（model_override
  字段，不在 LoopRuntime 里塞 per-session 表——避免跨会话污染）。
- **model-visible-means-logged 不变**：真模型走 `run_turn` 既有流水线，流式 chunk 逐块落盘，
  kill -9 恢复语义天然继承（热升级过渡态前提）。
- **minimax 探测端点**：实测 `GET {base}/v1/models` 返回 OpenAI 标准 `{data:[...]}`；
  `/models/list` 404。`ModelListEndpoint::MinimaxList` 已删除，统一 Standard。
- **reasoning_content**：仅当模型名含 `m3`/`deepseek-reasoner` 时解析（MiniMax-M3 实测
  带 `<think>` 推理增量 → ReasoningDelta，wire 侧 `reasoning` 块，不进上下文）。
- **serde_json 键序**：无 `preserve_order` 时 Map 按键字母序序列化（`error < ok`）——
  修正了 M2.5 遗留的 rpc.rs 测试期望串（当时只跑了 gate25/conformance，JSON 解析比对
  不敏感键序）。
- **错误形状**：credentials 非法 ref 走 `bad-request`（Wire 前端 zod 校验需要 details 恒有）。
